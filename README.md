# CircularTech

A responsive website demonstrating a sustainable device subscription
concept based on a circular supply chain.

## Features

- Home page introducing the concept
- Subscription plans and illustrative pricing
- Circular supply chain process
- Sustainability information
- Project background and credits
- Mobile navigation and a demonstration contact form

## Technologies

- HTML5
- CSS3
- JavaScript

## Run Locally

Download or clone this repository, then open index.html in a browser.
No package installation or build step is required.

## Project Structure

- index.html — Homepage
- how-it-works.html — Subscription and refurbishment process
- plans.html — Pricing, FAQs, and demo contact form
- impact.html — Sustainability information
- about.html — Project background and credits
- css/style.css — Website styles
- js/script.js — Browser interactions
- images/ — Website images

This is an academic demonstration. It does not process payments,
provide real subscriptions, or send contact-form messages.

CI/CD and automated deployment have not yet been configured.
